# Student Mental Wellness Score Prediction

An educational machine learning project that predicts a student wellness score based on academic, lifestyle and social factors.

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib

## ML Models

- Linear Regression
- Random Forest Regression
- Gradient Boosting Regression

## Project Workflow

Data Generation
→ Data Preprocessing
→ Exploratory Data Analysis
→ Feature Engineering
→ Model Training
→ Model Comparison
→ Hyperparameter Optimization
→ Prediction

## Evaluation Metrics

- MAE
- RMSE
- R² Score

## Optimization

Random Forest hyperparameters were optimized using GridSearchCV.

## Disclaimer

This project is intended for educational and machine-learning practice purposes only. The predicted wellness score is not a medical or psychological diagnosis.
